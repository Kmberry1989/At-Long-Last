# At Long Last visual review captures

These PNGs are local review artifacts captured from the game UI and Three.js board renderer. The board theme captures were made from the same board layout with each supported theme applied.

## Board themes

Open each PNG in `board-themes/`: `cozy`, `garden`, `beach`, `city`, `holiday`, `starlit-rooftop`, `autumn-embers`, `cherry-blossom`, and `aurora-veil`.

## Night flow

`night-loop/` contains the captures completed before the local end-to-end run hit a missing dice-result confirmation on a later normal landing. It includes paired lobby, kiss recording/preview/sent and pucker states, first-player coin toss, ready board, dice tumble/result, piece hopping/landing, coin flip, moment-card back/reveal, and resolved-card board states. Later activity, mini-game, finale and scrapbook screens were not captured because that failure stopped the loop. The generated screenshot set should not be read as proof of a complete successful playthrough.

The pucker capture seeks the display and heart animations to show their compressed phase; normal playback animates continuously, with reduced-motion preferences respected.
