# Connect Four finale and collection assets

Generated master artwork for the Connect Four finale. The app uses compressed WebP derivatives in `public/assets/connect-four/` so phones do not need to download the full-size PNG masters.

- `board-concept.png`: empty 7-column by 6-row heirloom-style board, burgundy velvet, mahogany, and antique brass.
- `player-heart-token.png`: rose enamel and heart piece.
- `player-crescent-token.png`: midnight teal enamel and crescent piece.

The original two token masters remain as first-pass concept references. The current game uses the generated, face-on nine-token atlas (`token-atlas.png`) and its optimized WebP copy. The board art is a visual shell; the 7×6 spaces and falling pieces are interactive UI layered on top.

The nine token motifs are garnet heart and crescent moon (available immediately), then leaf at 3 shared nights, key at 7, shell at 14, lantern at 25, letter at 40, blossom at 60, and compass at 100. Unlocks are shared couple milestones, never cost hearts, and are cosmetic only.
