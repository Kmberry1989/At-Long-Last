# Connect Four finale and collection assets

Generated master artwork for the Connect Four finale. The app uses compressed WebP derivatives in `public/assets/connect-four/` so phones do not need to download the full-size PNG masters.

- `board-concept.png`: empty 7-column by 6-row heirloom-style board, burgundy velvet, mahogany, and antique brass.
- `player-heart-token.png`: rose enamel and heart piece.
- `player-crescent-token.png`: midnight teal enamel and crescent piece.

The original two token masters remain as first-pass concept references. The current game uses two generated, face-on nine-token atlases (`token-atlas.png` and `token-atlas-2.png`) and optimized WebP copies. The board art is a visual shell; the 7×6 spaces and falling pieces are interactive UI layered on top.

The 18 token motifs are garnet heart and crescent moon (available immediately), then leaf at 3 shared nights, key at 7, shell at 14, lantern at 25, letter at 40, blossom at 60, compass at 100, candle at 125, teacup at 150, cottage at 175, paintbox at 200, hourglass at 225, umbrella at 250, picnic basket at 275, music box at 300, and sunrise hills at 365. Unlocks are shared couple milestones, never cost hearts, and are cosmetic only. Each player selects one token per match; all of that player's pieces use the same design for the full match.
