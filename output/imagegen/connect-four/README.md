# Nightly Connect Four concept assets

Initial visual exploration only; these images are not wired into gameplay.

- `board-concept.png`: empty 7-column by 6-row heirloom-style board, burgundy velvet, mahogany, and antique brass.
- `player-heart-token.png`: rose enamel and heart piece.
- `player-crescent-token.png`: midnight teal enamel and crescent piece.

The two tokens are visual alternatives for player sides. The board’s holes and tokens should be rebuilt as separate interactive scene geometry if this concept is approved.
